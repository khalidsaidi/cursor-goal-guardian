# Changelog

## 1.0.3

- Show delivered work and useful findings, with diagnostic records available under Check details and no retry button. Routine agent replies describe the result without asking users to manage internal checkers.
- Keep the current goal's display separate from earlier goals, preventing old review failures from appearing on a new task.
- Preserve learning results when Windows briefly locks a feedback or replay cache file, without making another model call.
- Correct the first-request checklist and give small-project reviews their source up front, with time to return a verdict.

- Load the panel’s bundled styles and script directly in its nonce-protected HTML, avoiding failed remote asset requests that can leave WSL setup blank.
- Start setup with Connect Guardian; goal and boundary fields stay available under optional settings.
- The installed Linux candidate completed the existing CSV task in real Cursor, reusing the implementation and recorded checks; both completion checks passed.

## 1.0.2

- Restore complete native package builds for the existing Windows, macOS and Linux targets on x64 and ARM64. Complete packages execute in native platform checks with a stand-in model.
- Include ADK and the Codex goal runtime in every platform package.
- Preserve long, multiline and non-English requests through Windows reviewer, evaluator and learning calls.
- Execute complete native packages before publication and publish those checked artifacts.

## 1.0.1

- Keep the goal engines complementary: DeepSeek controls goal status and rounds; Codex supplies usage accounting, budgets and continuation instructions.
- Reuse relevant work and checks so the agent can finish remaining items without repeating valid verification.
- Give the independent checkers actual project evidence and keep findings focused on missing work, real defects and meaningful unrequested changes.
- Connect specific panel and chat corrections to current reviews and eligible RRSI learning, retaining the user's reason and useful findings.
- Bound background learning, yield to active work, retain compatible progress and offer Off, Light and Standard controls.
- Refresh the public guides, listing, interface wording and illustrated tour around helping a normal agent finish the user's work.

Version 1.0.1 was built and validated for Linux x64, including WSL Ubuntu. Reviews can be wrong or incomplete; background learning is not a promise of improvement from every correction. See the verification guide for the evidence and its limits.

Earlier entries are preserved in the [historical changelog](https://github.com/khalidsaidi/cursor-goal-guardian/blob/main/docs/history/changelog-before-1.0.1.md). Older platform artifacts and historical counts do not describe the current release.
